- Intended outcome: consent-gated PostHog analytics use the TRIAD API first-party `/e/*` proxy
  without leaking browser credentials, provider errors, redirects, or caller-selected destinations.

- Adjacent regressions: public landing rendering, lead CTA visibility, site build, API routes, and
  deployment environment mapping.

  replay, no lead values, sanitized logs and failures.
- Out of scope: production PostHog ingestion and replay confirmation until the protected deployment
  completes; lead persistence was unchanged and covered by the baseline.
