The analytics portion of MVP-S1 passed. The campaign-entry portion remains
blocked because the site calls an API contract that is not integrated. A later

The essential-only and initial consent screenshots were inspected. The first

## Campaign entry — blocked

The site contract is defined at
`apps/site/src/pages/c/index.astro:69` and requests:

```text
GET /campaign-links/:slug/resolve
```

No matching route, module, or migration-backed campaign-link model exists under
`apps/api/src/**` or `apps/api/drizzle/**`. The real browser journey received a
non-2xx API response (404 in one run and 500 in a later run), emitted the
corresponding resource error, and rendered “Não encontramos este link”. The
fallback screenshot was inspected and visually coherent, but it is evidence of
the missing happy-path contract, not acceptance of campaign entry.

## Empty-database migration chain — blocked

A subsequent rerun did not reach Playwright tests. Migration startup failed with
PostgreSQL code `42710` because
`commercial_lead_activities_related_activity_id_fk` was created twice:

- `apps/api/drizzle/0004_aberrant_puppet_master.sql:127`
- `apps/api/drizzle/0021_flawless_raider.sql:14`

Keystone owns the correction and has confirmed the intended bounded change:
remove only the six duplicate CHECK constraints and duplicate FK from `0021`,
while preserving declarative schema/snapshot state and keeping the migration
strictly additive. No further QA attempt is authorized until the empty-database
chain is confirmed passing.

## Scaffold reliability finding

Before the migration failure, the host contained 30 orphaned PostgreSQL
processes belonging exclusively to the suite prefix
`crv-web-e2e-integrated-postgres-*`, exhausting shared-memory IDs. The processes
were stopped through their individually validated cluster directories; residual
directories were not automatically removed. The Playwright API webServer now
uses a 10-second graceful `SIGTERM` shutdown window so the existing path-guarded
cleanup can finish. No broad target or non-suite database was stopped or
deleted.
