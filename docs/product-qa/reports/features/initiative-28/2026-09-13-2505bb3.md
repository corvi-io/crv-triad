## Privacy, Access, And Tenant Isolation

- Product event properties use explicit allowlists; credentials, tokens, request bodies, private headers,
  e-mail addresses, and user-submitted business payloads are excluded.
- Replay masks all text and inputs. Exception payloads are sanitized before transmission.
- PostHog tenant grouping uses the authenticated tenant UUID; logout resets the browser identity.
- Provider administration uses a project-restricted personal key with only `Error tracking: Write`, stored
  in Infisical as `INFRA__POSTHOG_CLI_API_KEY` for `dev`, `hml`, and `prd`.
