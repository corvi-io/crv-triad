# Security Policy

CRV Triad is a private internal product. Do not disclose suspected vulnerabilities in public issues,
pull requests, commits, or logs.

Report security concerns privately to the repository owner with:

- the affected component and environment;
- reproduction steps that avoid real credentials or personal data;
- the expected and observed behavior;
- a proposed mitigation, when known.

Never include tokens, passwords, database URLs, private headers, customer data, or production payloads
in a report. Rotate any credential that may have been exposed before continuing investigation.
