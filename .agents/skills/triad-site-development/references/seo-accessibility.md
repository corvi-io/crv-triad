# Site SEO And Accessibility

## SEO

- Preserve static, crawlable HTML for marketing content.
- Keep metadata, canonical URLs, Open Graph data, sitemap behavior, and robots
  behavior accurate when pages/routes change.
- Check generated titles and descriptions for clarity, uniqueness, and truncation
  risk.
- Update durable SEO docs when a convention or indexing behavior changes.

## Accessibility

- Use semantic HTML before custom ARIA.
- Provide accessible names for icon-only controls.
- Keep focus visible and keyboard navigation complete.
- Ensure form errors are associated with fields.
- Do not rely on color alone to communicate state.
- Ensure decorative imagery does not create horizontal overflow on mobile.

Use the `accessibility` skill for deeper WCAG audits when the request or risk
requires it.
